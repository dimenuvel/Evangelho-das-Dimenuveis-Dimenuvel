## 🌌 1. O que é esse jogo, afinal?

**DIMENUVEL: OS ÚLTIMOS ABIDANTES** é um jogo completo de defesa de torres (Tower Defense) no mais puro estilo arcade cósmico retrô dos anos 80/90. Com gráficos blocky estilo fliperama, sintetizadores gerados ao vivo no navegador e uma pitada generosa de filosofia existencial descontraída, sua missão é impedir que as **Distorções Cósmicas** destruam a **Cinza Sagrada** no centro da Espiral.

Tudo funciona **100% offline**, sem login, sem telemetria chata, sem microtransações e com suporte bilíngue completo em tempo real (**Português do Brasil 🇧🇷** e **Inglês 🇺🇸**).

## 👾 3. Quem são os Invasores? (As Distorções)

Nem todo habitante da Espiral entendeu a mensagem do Evangelho. Prepare-se para enfrentar:

* 🌀 **O Vazio**: A distorção básica e apressada.
* 👻 **O Falso**: Fica piscando e esquivando dos seus disparos com salto de fase quântico.
* ⚡ **O Andarilho (Stepper)**: Veloz como o vento cósmico, tentando passar despercebido.
* 🛡️ **O Materialista**: Blindado com 65% de resistência física. Requer dano solar e energia bruta!
* ⚠️ **O Agitador**: Diminui o ritmo de ataque das suas torres ao passar.
* 🌫️ **O Silenciador**: Avança com camuflagem furtiva invisível a olho nu.
* 👽 **O Estranho**: Uma anomalia de elite imprevisível que teleporta no mapa.
* 👑 **O Grande Vazio**: O chefão supremo em múltiplas fases cósmicas que vai testar sua paciência e sabedoria abidante!

## ⚡ 4. Decretos da Ressonância Espiral

Ao derrotar inimigos, você acumula energia de Ressonância. Quando a barra atingir 100%, você pode invocar um dos **4 Decretos Sagrados**:

1. ⏳ **Quietude Temporal**: Reduz a velocidade de todos os monstros no mapa para 20% por 6 segundos.
2. 💫 **Espiral Dourada**: Dobra a cadência de fogo das suas torres com 100% de ataques críticos por 8 segundos.
3. 🧘 **Presença Silenciosa**: Repara imediatamente +35% da saúde da Cinza Sagrada.
4. 💥 **Reinício Cósmico**: Onda de choque apocalíptica dourada que aniquila as fileiras invasoras.

## 🎮 5. Recursos e Destaques

- 🇧🇷 / 🇺🇸 **Troca Instantânea de Idioma**: Alterne entre o *Evangelho das Dimenúveis* e o *Gospel of Dimenuous* em um toque de botão (com ícone da bandeira).
- 🔊 **Áudio Procedural Chiptune/Sintetizador**: Sons de torres, laser, explosões e música ambiente relaxante gerados matematicamente direto pela **Web Audio API** (sem arquivos de áudio pesados).
- 📺 **Modo CRT Vintage Opcional**: Quer aquela nostalgia pura de tubo de TV com scanlines e curvatura retrô? Ative nos Ajustes!
- 🗺️ **3 Modos de Jogo**:
  - 📖 **Campanha**: A jornada pelos 7 Estratos com conselhos oportunos de *O Cara*.
  - ♾️ **Infinito**: Ondas geradas proceduralmente com escala infinita de dificuldade para bater recordes.
  - 👑 **Os Últimos Abidantes**: Modo desafio hardcore com essência escassa e mutações impiedosas.
- 📜 **Códice das Dimenúveis**: Enciclopédia viva de sabedoria cósmica, fraquezas de inimigos e segredos da Espiral.
- 🏆 **12 Conquistas & Sistema de Estrelas**: Salvas localmente no aparelho (sem contas, sem internet).

## 🛠️ 6. Pilha Tecnológica (Stack)

* **Motor Gráfico**: React 19 + TypeScript + Renderizador HTML5 Canvas 2D cravado a 60 FPS.
* **Interface & Estilo**: Tailwind CSS + Lucide Icons + Motion (animações fluidas).
* **Motor Nativo Mobile**: Capacitor 8 configurado para Android nativo (SDK 34).
* **Esteira CI/CD**: GitHub Actions automatizado com **Java 17 Temurin**, Gradle e build de APK Release assinado.

## 🚀 8. Como Rodar Localmente (Desenvolvimento Web)

### 1. Clonar o repositório:
```bash
git clone https://github.com/dimenuvel/Evangelho-das-Dimenuveis-Dimenuvel.git
cd Evangelho-das-Dimenuveis-Dimenuvel
```

### 2. Instalar dependências:
```bash
npm install
```

### 3. Iniciar o servidor de desenvolvimento:
```bash
npm run dev
```
Acesse `http://localhost:3000` no seu navegador! (Dica: abra o DevTools no modo de emulação de celular em modo paisagem para a experiência perfeita).

### 4. Validar e compilar:
```bash
npm run lint
npm run build
```

## 📱 9. Como Gerar e Baixar o APK do Android

### ☁️ Opção 1: Direto pelo GitHub Actions (Mais Fácil!)

Você não precisa instalar o Android Studio no seu computador:
1. Abra a aba [**Actions**](https://github.com/dimenuvel/Evangelho-das-Dimenuveis-Dimenuvel/actions) do repositório no GitHub.
2. Clique no workflow **Build Android APK** na barra lateral.
3. Clique em **Run workflow** (Executar fluxo de trabalho).
4. Aguarde a compilação finalizar com sucesso (ícone verde ✅).
5. Na parte inferior da página da execução, na seção **Artifacts**, clique para baixar o arquivo zip:
   `DIMENUVEL-OsUltimosAbidantes-v1.0-APK.zip`
6. Extraia o arquivo para obter seu APK:
   `DIMENUVEL-OsUltimosAbidantes-v1.0.apk`

---

### 💻 Opção 2: Compilando Localmente com Android Studio / Gradle

**Requisitos**:
* Node.js 20+
* Java JDK 17 (Recomendado: Eclipse Temurin 17)
* Android SDK Platform 34 e Build-Tools

**Passos**:
```bash
# 1. Compila os arquivos web da aplicação
npm run build

# 2. Sincroniza com a pasta nativa do Android
npx cap sync android

# 3. Compila o APK via Gradle
cd android
./gradlew assembleRelease
```
O APK final será gerado no diretório:
`android/app/build/outputs/apk/release/`

## 📲 10. Como Instalar no Celular Android

1. Transfira o arquivo `.apk` para o seu celular (via WhatsApp, Telegram, Google Drive ou cabo USB).
2. Abra o gerenciador de arquivos do celular e toque no APK.
3. Se o Android exibir o aviso de segurança, selecione **"Permitir desta fonte"** nas configurações.
4. Toque em **Instalar**.
5. Abra o jogo, coloque os fones de ouvido e aproveite a jornada pelas Dimenúveis!
